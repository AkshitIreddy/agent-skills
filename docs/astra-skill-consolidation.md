# Skill consolidation - September 2026

This update follows [OpenAI's September 11 guidance on skills and prompts for
GPT-6 Astra](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra).
It keeps concrete quality and execution requirements while narrowing triggers,
consolidating overlapping workflows, and loading detailed guidance only when needed.

## Retired names

| Retired skill | Replacement | Preserved behavior |
| --- | --- | --- |
| ambitious-implementation | frontend-design | Bespoke craft, materials, motion, and audio treatment |
| build-and-look | try-it-first | Early prototypes and meaningful rendered comparisons |
| playwright-qa | visual-verification | Actual browser interactions and honest temporal evidence |
| keep-going | finish-the-list | Complete requested work and report real blockers |

The retired folders should be removed from existing installations after a
backup; update project instructions that explicitly invoke their old names.
The keep-going name was previously used in some personal installations and was
not part of the earlier public catalog. No automatic alias entries are retained.

## Distinct workflows kept

Frontend design owns aesthetic decisions, while build-without-fear owns
subsystem state and recovery. Try-it-first resolves uncertainties; visual
verification establishes rendered and interaction evidence. Audio verification
retains its specialized measurement helper. Research remains available for
decisions affected by current technique evidence, without a universal source quota.

The collection now contains 17 public skills, including portable hidden-terminal
and secondary-monitor workflows. Private company deployment skills, built-in
system skills, and plugin-managed skills remain outside the public collection.

## Installation boundary

Replace only the public package folders and the four retired names. Preserve
other local packages. Include supporting references and license files, not only
SKILL.md. Verify complete package file lists and hashes after copying.

The explicit-only invocation policy of adversarial-refinement-loop is preserved.
The Windows placement helper provides best-effort positioning; its limitations
are documented. The interactive debugging shell template is retired in favor
of a direct, redacted reproduction request when human input is necessary.

Structural checks establish valid packages and links. They do not demonstrate
that every future model run will choose or execute the workflows correctly.
