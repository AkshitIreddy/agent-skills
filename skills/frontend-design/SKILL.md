# Design the intended experience

Modified from Anthropic's frontend-design skill and combined with original
craft guidance. Distributed under the accompanying Apache 2.0 license.

Follow the user's subject, audience, content, and aesthetic direction. The craft
reference also applies to game and application assets beyond web pages. Preserve
an established design system unless the task calls for changing it. Make routine
reversible choices from context; ask only when missing information materially
changes the product. Keep a small fix focused on the affected component.

For a new page or substantial restyle, read
[design direction](references/design-direction.md) for typography, composition,
content, and critique. For richer materials, animation, or sound treatment, read
[craft detail](references/craft-detail.md). Load only the relevant reference.

Build a real result early, compare meaningful alternatives when useful, and
integrate the chosen direction into the requested interactions and states.
Judge quality from the rendered product. Code size and effect count are not
quality targets; minimal work demands precision and maximal work demands depth.

Complete the brief with readable content, accessible controls, responsive
layout, and motion appropriate to the design. Inspect the changed surface at
readable scale and exercise affected interactions. Report unresolved evidence
gaps instead of claiming unobserved visual or audio quality.
