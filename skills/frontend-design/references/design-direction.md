# Design direction

Modified from Anthropic's frontend-design skill for task-proportionate workflows.
Distributed under the accompanying Apache 2.0 license.

## Ground the design in the brief

Use the actual subject, audience, content, and job of the interface. Resolve
routine choices from context; ask when choosing the subject would change what
the user receives. Preserve explicit aesthetic choices and existing design
systems. Previously available preferences can inform choices without replacing
the current brief.

## Make coherent choices

- Give typography an intentional scale, weight, measure, and rhythm. Choose
  font roles that serve the content rather than requiring a particular count.
- Make palette and materials specific to the subject. A familiar palette can
  be appropriate when it follows the brief.
- Let layout express hierarchy and relationships. Numbering should represent
  an actual sequence, and structural labels should communicate useful meaning.
- Use motion where it clarifies interaction or supports the atmosphere. Honor
  reduced motion and preserve fast, interruptible input.
- Match complexity to the vision. Maximalist work needs depth; minimal work
  needs precise spacing, type, and detail.

For a substantial design, a compact palette/type/layout plan or rough wireframe
can help compare directions. Build early enough to challenge assumptions with
rendered evidence. Revise the plan when the result shows a better approach.
A fixed number of colors, fonts, passes, or aesthetic risks is unnecessary.

## Copy is interface material

Use language the intended user recognizes. Name actions consistently across
buttons, confirmations, and notifications. A label should explain the control;
implementation details belong only where they help a meaningful decision.

Make errors and empty states explain the next useful action. Use specific,
accurate content and plain verbs, with the tone matched to the audience.
Draft missing copy where appropriate without inventing factual claims.

## Critique the actual result

Inspect the integrated design for hierarchy, legibility, responsive layout,
keyboard focus, and coherence. Remove decoration that competes with the brief.
Record reusable project decisions only in an appropriate existing location;
persistent memory updates require the user's authorization.
